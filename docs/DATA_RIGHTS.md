# Data and image rights

Visual World is an index, not a claim of ownership over source material.

- Repository code is MIT licensed.
- Metadata licensing and image licensing are stored separately.
- A source publishing CC0 metadata does **not** imply its images are CC0.
- Public-domain or open images may be rendered from the source CDN/IIIF endpoint when the source record permits it.
- Restricted works retain metadata and an outbound link rather than copying a high-resolution image.
- Each connector must preserve source-specific rights information and must not upgrade an unknown or restricted image to public domain.
- The public canonical image is selected only from a source record marked `public_domain=1` that provides an image URL. Metadata licenses never authorize image display by themselves.
- A canonical work marked public domain means at least one source record has that status; the detail view shows each source's metadata license, image license and rights note separately.

Always consult the linked institution record for authoritative, object-level rights information.
